# 第一版验证记录

日期：2026-10-01。验证基于本目录中的实际实现；平衡性仍需要玩家试玩调优。

## 已执行

- `npm test`：20 项游戏逻辑测试全部通过。
- `npm run check`：游戏、渲染、UI 与服务器 JavaScript 语法检查通过。
- `npm run test:browser`：11 项 Chromium 浏览器交互测试全部通过。
- `npm start`：本地 5173 服务已启动，HTTP 返回 200。
- 已实际查看首页、探索、战斗、Boss 红格预警、死亡、胜利和小屏桌面截图；游戏视野、像素角色、HUD 与覆盖界面正常呈现。

## 产品需求与证据对应

| 需求 | 证据 |
| --- | --- |
| 200×200 地图、3×3 出生空地、远处 7×7 Boss 区 | 逻辑测试覆盖 15 个种子的格数组与范围，检查安全出生和三种怪物/高级武器存在 |
| 固定世界、重新开局不同地图 | 同种子生成一致、不同种子地形不同；浏览器重新开局检查新种子 |
| 空地岛屿、部分天然道路 | `Game.generate` 先铺房间，再概率连接邻近房间；地图从生成起固定，所有木头均可砍除 |
| 9×9 视野、木头不遮视线、探索记录 | 逻辑测试检查 81 格初始揭示、隔树可见与探索记忆；查看主地图与小地图截图 |
| 没有全图或 Boss 指向、视野外无怪物点 | `Renderer.minimap` 只画附近已探索格，敌人点由 `visible` 过滤；UI 无全图或方向入口 |
| 按格移动、平滑动画、移动中攻击 | 逻辑检查边界/木头/敌人阻挡以及攻击保留移动状态；浏览器使用实际方向键和空格拓荒 |
| 三种武器、1/3/6 格挥砍、木头一刀清除 | 逻辑检查三个等级的四方向形状和木头清除；浏览器检查大剑装备及拒绝降级 |
| 走上食物回血、满血保留 | 逻辑检查满血保留和精确回血；浏览器实际走上食物从 50 恢复至 85 |
| 怪物不能穿树、连接后追击、绕路 | 逻辑检查封闭空地不警觉，砍通后追击，障碍绕路与较长的连通路径 |
| 蓄力攻击可躲、三类属性、脱战保留状态 | 逻辑检查预警前无伤害、走开躲避、命中扣血、受伤保护、脱战不回血 |
| 无定时刷新、击杀掉落 | 击杀后持续更新不再出现敌人；可控随机源检查武器和食物掉落 |
| Boss 预警攻击、撤退回满血、直接通关 | 逻辑检查延迟伤害、区域退出和胜利；浏览器保存预警、重载后撤退，核对 Boss 回到 620 生命 |
| 自动存档与刷新继续 | 逻辑逐项比较恢复后的地图、视野、玩家、敌人、物资、Boss 和统计；浏览器刷新保留坐标和砍树数 |
| 损坏/不可写存档可见反馈 | 逻辑拒绝无效角色与预警数据；浏览器模拟损坏 JSON 和存储写入失败，仍可新开局游玩 |
| 死亡清档、丢装备并重新生成 | 浏览器实际等待敌人攻击致死，检查 localStorage 清空，重新开局为满血、小刀和新种子 |
| Esc/失焦/隐藏暂停，返回不自动继续 | 逻辑比较暂停前后完整状态；浏览器检查 Esc、blur 与 visibilitychange 处理及冻结计时 |
| 通关统计与停止仿真 | 浏览器攻击 Boss，核对 01:23 和 8 次击败，胜利后输入不移动，刷新仍显示胜利结果 |
| 新开局覆盖确认 | 浏览器分别执行返回当前进度和确认覆盖 |
| 页面实际渲染、桌面适配 | 浏览器检查无运行时异常、无横向溢出、1024×800 中游戏区域底部仍在视口内，截图目视核对 |

## 验证边界

浏览器测试使用 Chromium，未声称已覆盖全部浏览器。Boss、死亡和特定物资场景通过构造并载入真实格式的存档进入，再使用真实键盘交互验证；未用自动化连续探索完整 40,000 格世界。测试证明规则与流程工作，不能替代长期游玩的难度与乐趣评估。页面隐藏处理测试通过派发 visibilitychange 验证事件逻辑，失焦通过 blur 事件验证。
