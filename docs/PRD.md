# Fearless Soldier · 无畏士兵

版本：0.2.1 / 2026-10-01。本文是本项目第一版的产品与验收基准。

## 目标

制作电脑浏览器中的俯视角像素风 2D 探索游戏。玩家从树林中的 3×3 空地出生，用刀拓荒，连接空地、发现食物和武器、与怪物战斗，并最终击败 Boss。胜利条件只有击败 Boss，不设饥饿、建造、钥匙或强制清图任务。

## 已确认的玩法

1. 每局生成有限的 **100×100 格**地图。生成后木头、空地、物资和敌人的初始位置固定，砍树不会随机生成事件。出生点附近安全。
2. 地图主要为木头，散布不同大小的空地岛屿；部分空地由天然曲折小路连接，其余需要砍通。Boss 在较远位置，周围预留约 **7×7 格**战斗空地。不得生成封闭到无法砍出的区域。
3. 主视野为以士兵为中心的 **9×9 格**。木头阻挡移动但不遮挡视线，范围内空地、物资与怪物可以提前看到。视野之外隐藏。
4. 左上角圆形小地图显示附近已探索地形，并记住探索记录；视野外怪物不显示。**没有可展开大地图，没有 Boss 方向提示。**
5. WASD 或方向键按格移动，按住连续移动。士兵始终固定在屏幕正中心，地图和其他对象通过同一插值镜头平滑滚动；包括跨格、暂停恢复和地图边缘都不得跳动。空格每次按下攻击一次，允许边移动边攻击，朝向为最后一次移动方向。只用走位躲避，不提供冲刺或翻滚。
6. 攻击范围内的木头一刀清除。挥砍应有实际刀刃摆动、刀光、命中火花、怪物闪白与受击后仰、短暂命中停顿和音效。怪物攻击表现为蓄力、挥击或扑咬；Boss 有砸击冲击波。所有位移特效不能把士兵移离屏幕中心。三种武器攻击速度相同：小刀前方 1 格；长刀前方一排 3 格；大剑前方两排共 6 格。伤害逐级提高。
7. 武器既可在空地找到，也可由怪物掉落。走到武器上自动拾取，只自动装备更强武器，弱武器不能降级当前装备。
8. 食物走上去自动使用，恢复生命；满血时留在地面。不设背包或手动吃东西操作。
9. 普通怪物包括僵尸（慢）、野狼（快、血少）、兽人（血厚、伤害高）。未警觉时在连通空地随机游走，走动之间短暂停顿，朝向随移动方向更新；视野外也会游走。不能越过木头、地图边界、士兵或其他怪物，不能消耗地面物资。靠近约 4 格且有空地道路连通时，立即切换为追击。
10. 怪物相邻后先蓄力再攻击，危险格可辨认，玩家可以移动躲避。脱战后保留当前位置及剩余血量，取消攻击，短暂停顿后恢复游走；不会瞬移回出生点或回血。
11. 怪物与物资均不定时刷新。击杀后可能掉落物资，属于击杀奖励；已清理区域不会自行生成怪物，但其他怪物可沿已连通的空地游走进入。
12. Boss 通过红色格子预告范围攻击，攻击后留出输出空隙。玩家可随时离开战斗区域撤退，Boss 脱战后恢复满血。找到后即可挑战，没有钥匙门槛。
13. 难度为适度挑战：食物有限，多怪有危险，越远离出生点整体越危险。长局探索不强制限定 10 分钟。
14. 自动保存这一局的地图改动、探索记录、角色、敌人、物资和计时。刷新或重新打开可继续；死亡清除本局存档，重新开局重新生成地图并失去装备。
15. Esc 暂停；离开标签页自动暂停，回来需手动继续。暂停期间怪物、预警、移动和计时全部停止。
16. 击败 Boss 直接结束，展示本局用时、探索比例和击败怪物数量，提供重新开局。

以下为实现选择，并非访谈中锁定的最终平衡数值。统一维护在 `src/game.js` 的配置表中。

| 挥刀间隔 | 0.24 秒 |
| 小刀 / 长刀 / 大剑伤害 | 15 / 28 / 48 |
| 食物回血 | 35 |
| 僵尸 / 野狼 / 兽人生命 | 45 / 30 / 100 |

## 页面与交互

- 首页/暂停界面展示标题、操作说明、继续/开始按钮。
- 游戏画布铺满浏览器视口，不设页头、外置侧栏、底部记录或滚动区域。士兵固定于视口中心。左上角显示圆形小地图，右下角半透明 HUD 显示士兵状态和当前装备。宽屏外围为探索迷雾，可行动主视野仍为 9×9 格，不显示范围外物资或敌人。
- HUD 内紧凑显示局内时间、坐标、砍树数、击败数、探索比例。拾取反馈仅短暂浮现在画面内，坐标不会泄露 Boss。暂停与音效开关在右上角。
- 新开一局会覆盖现有进度，已有进度时提供明确的确认；死亡后的重新开始无需再次确认。
- 保存失败要有可见反馈，不能声称已成功保存。存档带版本标识，损坏存档不能阻止新开局。100×100 地图使用 v2 独立存档；旧 v1 的 200×200 存档保留，不静默覆盖，开始页提示玩家在新版地图重新出发。移动中的插值进度保存，暂停或刷新不得使镜头跳格。
- 移动/攻击是实际键盘操作，页面滚动不应抢走方向键与空格。

## 技术方案

原生 JavaScript ES modules + Canvas 2D，使用代码绘制像素角色、树林、武器和地面。游戏状态与渲染分离，游戏逻辑可在 Node 环境测试。地图用格数组，敌人和物资维护独立状态。localStorage 保存当前一局，不依赖服务器账户。提供无第三方依赖的本地 HTTP 启动脚本。

## 第一版边界

本地单人、电脑键盘操作，无联网、触屏控制、账号、建造、饥饿、展开大地图、冲刺、远程武器或永久成长。挥刀、砍树、命中与拾取音效通过 Web Audio 实时合成，可静音；当前像素资源直接绘制，以完整玩法和可读反馈为验收重点。
